# countdown-timer

A customizable countdown timer for streams (OBS / Streamlabs), websites, or a full-screen browser tab. No API keys or accounts needed.

- `index.html` is the configurator. Set the time, text, format, style and effects, watch the live demo, then copy the link.
- `timer.html` is the timer itself. It reads all of its settings from the link.

Open `index.html` in a browser, or host both files together on any static host (for example GitHub Pages). Usage steps and the full list of link settings are on the configurator page.
